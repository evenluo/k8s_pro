# 核心 Kubernetes 课程评估 (Core K8s Assessment)

> 本模块内容将在 T019 任务中完整实现

## 评估概述

本评估将通过实际操作考核您对 Kubernetes 核心概念的掌握程度，包括：

- 集群管理和节点操作
- Pod 和 Deployment 生命周期管理
- Service 网络配置和服务发现
- ConfigMap/Secret 配置管理
- 多层应用架构部署

## 概念卡速记

> 📌 **概念卡：Assessment Scope（评估范围）**  
> **定义**：评估覆盖的能力清单，横跨集群运维、工作负载管理、网络与配置四大维度。  
> **准备提示**：将基础与核心课程的实验笔记整理成复习提纲，对照本清单逐项验证掌握程度。  
> **关联任务**：T019

> 📌 **概念卡：Scoring Matrix（评分矩阵）**  
> **定义**：实际操作、理论测试、故障排查的权重分配，用于衡量综合能力。  
> **准备提示**：合理分配复习时间，保持 70/20/10 比例，尤其重视实操部分的时间管理。  
> **关键动作**：完成多层应用部署、记录操作日志

> 📌 **概念卡：Readiness Checklist（过关清单）**  
> **定义**：评估前的自检清单，包括工具版本、命名空间、镜像仓库、脚本可用性等。  
> **准备提示**：参照 `./tools/validation/check-environment.sh` 输出，补齐缺口后再进入评估，避免耗时在环境问题。  
> **示例条目**：`kubectl auth can-i`、`kind get clusters`

## 评估形式

### 🎯 实际操作考核 (70%)
- 部署完整的多层应用（前端+后端+数据库）
- 配置服务间通信和负载均衡
- 实现配置的外部化管理
- 演示滚动更新和回滚操作

### 📝 理论知识测试 (20%)
- Kubernetes 架构组件理解
- 核心资源对象概念
- 网络和存储模型
- 最佳实践和故障排查

### 🔧 故障排查场景 (10%)
- 诊断和修复常见的集群问题
- Pod 启动失败问题分析
- 网络连接故障处理

## 通过标准

- 总分 ≥ 70% 视为通过
- 实际操作部分必须 ≥ 60%
- 能够独立完成应用部署和基础运维

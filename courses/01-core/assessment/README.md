# 核心 Kubernetes 课程评估 (Core K8s Assessment)

> 本模块内容将在 T019 任务中完整实现

## 评估概述

本评估将通过实际操作考核您对 Kubernetes 核心概念的掌握程度，包括：

- 集群管理和节点操作
- Pod 和 Deployment 生命周期管理
- Service 网络配置和服务发现
- ConfigMap/Secret 配置管理
- 多层应用架构部署

## 评估形式

### 🎯 实际操作考核 (70%)
- 部署完整的多层应用（前端+后端+数据库）
- 配置服务间通信和负载均衡
- 实现配置的外部化管理
- 演示滚动更新和回滚操作

### 📝 理论知识测试 (20%)
- Kubernetes 架构组件理解
- 核心资源对象概念
- 网络和存储模型
- 最佳实践和故障排查

### 🔧 故障排查场景 (10%)
- 诊断和修复常见的集群问题
- Pod 启动失败问题分析
- 网络连接故障处理

## 通过标准

- 总分 ≥ 70% 视为通过
- 实际操作部分必须 ≥ 60%
- 能够独立完成应用部署和基础运维

# 核心 Kubernetes 实验室 (Core K8s Labs)

本目录包含核心 Kubernetes 课程的所有实验练习。

## 实验列表

### 🏗️ 基础设施实验
- **kind-cluster.yaml** (T016) - Kind 集群搭建配置实验
- **nginx-deployment.yaml** (T017) - Web 应用部署实验
- **config-management.yaml** (T018) - ConfigMap/Secret 配置管理实验

## 实验特色

- 📋 **YAML 配置驱动** - 所有实验都使用配置文件定义
- 🔄 **渐进式难度** - 从集群搭建到复杂应用配置
- ✅ **自动验证** - 内置验证脚本确保实验效果
- 🛠️ **故障排查** - 包含常见问题解决方案

## 概念卡速记

> 📌 **概念卡：实验分层（Cluster → Workload → Config）**  
> **定义**：实验按“集群搭建 → 应用部署 → 配置管理”分层设计，与核心课程章节一一对应。  
> **学习提醒**：建议先完成上一层实验再进入下一层，防止基础配置遗漏导致后续实验失败。  
> **关联文件**：`kind-cluster.md`、`nginx-deployment.md`、`config-management.md`

> 📌 **概念卡：实验验证脚本（Lab Validators）**  
> **定义**：每个实验附带的命令或脚本，用于检查资源状态、日志与网络连通性。  
> **学习提醒**：完成实验后立即记录验证输出，形成“实验笔记 + 验证截图”资产，支撑后续评估。  
> **常用命令**：`kubectl get all -n <ns>`、`kubectl logs`

> 📌 **概念卡：复盘记录（Post-Lab Review）**  
> **定义**：对实验过程的总结，包括问题、分析、解决方案与改进建议。  
> **学习提醒**：建议使用 Markdown 表格记录复盘内容，为生产课程中的故障案例提供素材。  
> **模板提示**：`Issue | Root Cause | Fix | Prevention`

## 使用方法

每个实验包含：
- 📖 **学习目标** - 明确的实验目的
- ⚙️ **配置步骤** - 详细的操作指导
- ✅ **验证方法** - 确认实验成功的标准
- 🔧 **故障排查** - 常见问题和解决方案

## 环境要求

- Kind 0.17+
- kubectl 1.25+
- Docker Desktop 运行正常
- 4GB+ 可用内存
